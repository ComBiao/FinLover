# FinLover

Expense tracker. Next.js (App Router) + TypeScript + Tailwind + MongoDB/Mongoose + bcrypt/JWT. Single-root repo, **npm only**.

## Getting started

```bash
npm install
cp .env.example .env.local   # fill MONGODB_URI, JWT_SECRET, BCRYPT_SALT_ROUNDS
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
